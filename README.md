## 🕹️ Overview

Mednaffe provides an easy-to-use GUI for configuring and launching Mednafen, covering its many systems including PS1, PC Engine, and Neo Geo Pocket.

Whether you're a newcomer or a veteran, Mednaffe provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **System Selector** | Quickly select the target system for any ROM file |
| **Input Mapping** | Visual button mapping for keyboard and gamepad inputs |
| **Video Settings** | Configure shaders, scaling, and display modes per system |
| **Save Manager** | Browse and restore save states from a thumbnail grid |
